# Changelog

## 0.1.0

First release.

- `customs_check` — run the declaration rule pack over a JSON/YAML ledger.
- `customs_read_docx` — extract text from a `.docx` so it can be turned into a ledger.
- `customs_schema` — the column contract and every accepted alias.
- `customs_rulebook` — the rules, their basis kinds, and how many carry a verbatim clause (0 of 7 at this release).
